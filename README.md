# Tati Pretto Fotografia — Galerias

Site das galerias (seleção com marca d’água e fotos prontas estilo revista), publicado no Vercel.

- `index.html`, `app.js`, `painel.js`, `estilo.css`, `config.js`: o site.
- `demo/`: fotos de exemplo do modo demonstração.
- `apps-script/Code.gs`: cópia do código do Google Apps Script (cole em script.google.com; não suba a senha verdadeira aqui).
